# AutoBattler MVP

Автошахмат на Python + Pygame с системой покупки, слияния и продажи юнитов, предметами и тактическим полем 5×5.

## Технологии
- Python 3.14 + pygame-ce 2.5.8
- Pytest для тестирования

## Структура проекта
```
autobattler/
├── game/
│   ├── core/
│   │   ├── player.py      # Игрок: золото, резерв, доска, инвентарь
│   │   ├── shop.py        # Магазин: покупка, продажа, слияние ★1→★2→★3
│   │   ├── draft.py       # Фаза драфта
│   │   ├── pool.py        # Пул копий юнитов
│   │   └── team.py        # Сборка боевой команды
│   ├── battle/
│   │   └── engine.py      # Бой в реальном времени
│   ├── synergies.py       # Синергии классов и рас
│   └── round.py           # Логика раундов
├── ui/
│   ├── game_ui.py         # Интерфейс (драфт, бой, инвентарь)
│   ├── sprites.py         # Отрисовка спрайтов (PNG с альфа-каналом)
│   └── assets/sprites/    # PNG спрайты юнитов
├── data/
│   ├── units.json         # Конфигурация юнитов
│   └── items.json         # Конфигурация предметов
├── tests/                 # Pytest тесты
├── run_ui.py              # Точка входа
├── run_game.bat           # Батник запуска
└── .gitignore
```

## Как запустить
```bash
cd autobattler
python run_ui.py
```
Или через батник:
```bash
run_game.bat
```

## Управление в драфте
- `W` — купить юнита из магазина
- `S` — продать юнита из резерва
- `D` — поставить юнита на доску
- `F` — убрать юнита с доски в резерв
- `R` — reroll магазина ($1)
- `I` — купить предмет
- `A` — применить предмет к юниту
- `Enter` — начать раунд
- Мышь — клик по карточкам/клеткам, драг-н-дроп юнитов

## Тестирование
```bash
python -m pytest tests/
```
